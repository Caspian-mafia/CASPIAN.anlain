# CASPIAN — Online Multiplayer Game

مرجع اصلی نسخه آنلاین CASPIAN.

## تصمیم انتشار قطعی
- تنها موتور معتبر بازی، موتور آنلاین سمت سرور در Node.js + Socket.IO + PostgreSQL است.
- کلاینت وب/PWA و برنامه Android فقط رابط کاربری‌اند؛ هیچ تخصیص نقش، رأی، اقدام شبانه، نتیجه بازی، کیف پول یا جایزه‌ای را به‌صورت محلی تعیین نمی‌کنند.
- نسخه آفلاین مبتنی بر ربات و موتور محلی لغو شده و در این مخزن منتشر نمی‌شود.
- Android یک WebView امن از کلاینت اصلی همین سرور است و با متغیر HTTPS در زمان ساخت پیکربندی می‌شود.
- تا زمانی که سرور عمومی، PostgreSQL و دامنه با آزمون سلامت تأیید نشوند، نسخه آنلاین فعال یا آماده انتشار عمومی اعلام نمی‌شود.

## اجزای مخزن
- `server.js`, `rules-engine.js`, `scenario-runtime.js`: موتور و سرور authoritative.
- `public/`: کلاینت واقعی بازیکنان.
- `database/`: schema و migrationهای پایدار.
- `android/`: پوسته Android متصل به کلاینت زنده.
- `.github/workflows/`: آزمون‌ها و ساخت APK آنلاین.

## راه‌اندازی
Node.js 20+ و PostgreSQL لازم است. متغیرهای واقعی فقط در محیط استقرار تنظیم شوند؛ فایل `.env.example` صرفاً الگو است.

```sh
npm install
npm test
DATABASE_URL='postgresql://…' npm start
```

سرور باید `/health` را با `ok: true` و `storage: "postgresql"` پاسخ دهد.

## Android
گردش‌کار ساخت فقط با متغیر GitHub Actions به نام `CASPIAN_SERVER_URL` (origin عمومی HTTPS سالم) اجرا می‌شود. APK آنلاین از همان سرور کلاینت را بارگذاری می‌کند؛ هیچ موتور آفلاین یا بازی رباتی در برنامه اصلی وجود ندارد.

## وضعیت
مخزن سورس آنلاین در حال یکپارچه‌سازی است. استقرار عمومی، دامنه، اعتبارنامه‌های SMS/پرداخت، امضای release و آزمون چنددستگاهی نیازمند پیکربندی واقعی و شواهد جداگانه‌اند.

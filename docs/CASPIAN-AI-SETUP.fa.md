# راه‌اندازی دستیار هوشمند CASPIAN\n\nدستیار در همه صفحات عمومی برنامه به‌صورت دکمه شناور نمایش داده می‌شود و درخواست‌ها فقط از سرور عبور می‌کنند. کلید سرویس هرگز در کد مرورگر یا APK قرار نمی‌گیرد.\n\n## تنظیم سرور\n\nمقادیر زیر را فقط در فایل محیطی سرور تنظیم کنید:\n\n\`CASPIAN_AI_API_KEY\` (الزامی)، \`CASPIAN_AI_ENDPOINT\` (اختیاری، پیش‌فرض سازگار با API چت)، \`CASPIAN_AI_MODEL\` (پیش‌فرض \`gpt-4o-mini\`).\n\nپس از تنظیم، سرور را مجدداً راه‌اندازی کنید. مسیر \`GET /api/ai/status\` وضعیت آماده‌بودن سرویس را نشان می‌دهد. مسیر \`POST /api/ai/chat\` به نشست معتبر حساب یا پروفایل مهمان نیاز دارد.\n\n## امنیت و محدودیت‌ها\n\n- کلید API فقط در محیط سرور نگهداری شود و هرگز commit نشود.\n- دستیار به نقش مخفی، رأی خصوصی، اقدامات شبانه یا داده‌های پایگاه داده بازی دسترسی ندارد.\n- درخواست‌ها محدودسازی نرخ دارند و تاریخچه ارسالی به ۸ پیام اخیر و متن‌ها محدود می‌شود.\n- اتصال مستقیم به برنامه ChatMind/Sona بدون API یا SDK رسمی و مجوز توسعه‌دهنده امکان‌پذیر نیست؛ این پیاده‌سازی از یک endpoint سازگار با API چت استفاده می‌کند.\n- برای استفاده واقعی، کلید و مدل معتبر باید در سرور تنظیم و آزمون اتصال انجام شود.\n

# موانع انتشار و وضعیت فعال‌سازی CASPIAN

## تصمیم
نسخه آفلاین/رباتی لغو شده است. تنها نسخه قابل انتشار، کلاینت Android/Web متصل به سرور مرکزی آنلاین است.

## موارد آماده در سورس
- سرور Node.js + Socket.IO و لایه API.
- موتور قوانین و سناریوها.
- لایه PostgreSQL و schemaهای پلتفرم، مدیریت و امکانات اجتماعی.
- کلاینت اصلی بازیکن در `public/`.
- پوسته Android WebView که فقط HTTPS را می‌پذیرد.
- CI برای تست‌های آنلاین و workflow ساخت APK آنلاین.

## موانع واقعی پیش از فعال‌سازی
- [ ] سرویس Node.js در میزبان عمومی واقعاً ایجاد و اجرا شود.
- [ ] PostgreSQL production متصل، migrationها اجرا و backup تنظیم شود.
- [ ] دامنه gamefyconnect.net در رجیسترار فعال، DNS صحیح و TLS معتبر داشته باشد؛ وضعیت فاکتور/دامنه از این مخزن قابل تأیید نیست.
- [ ] `/health` از اینترنت عمومی `ok=true` و `storage=postgresql` پاسخ دهد.
- [ ] متغیر Actions با نام `CASPIAN_SERVER_URL` روی origin سالم تنظیم شود.
- [ ] CI و تست‌های بازی موفق شوند.
- [ ] APK آنلاین ساخته و روی گوشی واقعی آزمایش شود.
- [ ] آزمون چند دستگاه مستقل، قطع و وصل، rejoin، بازی کامل ۱۶ نفره، رأی‌گیری و مجوزها انجام شود.
- [ ] SMS، درگاه پرداخت و کلیدهای امضای release فقط از طریق secrets امن تنظیم شوند.
- [ ] نسخه Release امضاشده و تست‌شده برای انتشار فروشگاهی تولید شود.

## معنی خروجی‌ها
- موفقیت CI به معنی موفقیت تست‌های کد است، نه استقرار سرور.
- ساخت APK debug به معنی انتشار Play Store نیست.
- وجود render.yaml به معنی ایجاد سرویس Render نیست.
- دامنه ثبت‌شده بدون DNS/TLS سالم، سرور قابل اتصال ایجاد نمی‌کند.
- نسخه آفلاین یا APK نمایشی، جایگزین نسخه آنلاین نیست.

## نحوه فعال‌سازی
1. در میزبان، Web Service و PostgreSQL بسازید و متغیرهای محیطی را فقط در داشبورد امن میزبان وارد کنید.
2. دامنه را به میزبان متصل و HTTPS را فعال کنید.
3. `https://YOUR-HOST/health` را بررسی کنید؛ باید JSON سالم و PostgreSQL را گزارش دهد.
4. در GitHub → Settings → Secrets and variables → Actions → Variables مقدار `CASPIAN_SERVER_URL` را برابر origin HTTPS تنظیم کنید.
5. در Actions، workflow «Build CASPIAN online Android APK» را اجرا کنید.
6. artifact را دریافت و روی دو گوشی با اینترنت مستقل آزمایش کنید.

هیچ رمز، توکن، کلید پرداخت یا کلید دیتابیس را در گفت‌وگو یا commit وارد نکنید.

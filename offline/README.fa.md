# موتور آفلاین CASPIAN — محیط تمرین و آزمون

این پوشه نسخه حفظ‌شده موتور آفلاین/رباتی است. هدف آن تمرین تک‌دستگاهی، نمونه‌سازی و آزمون قوانین است؛ **این موتور مرجع اجرای بازی آنلاین نیست**.

## اتصال به موتور آنلاین
- نسخه آنلاین فقط از `server.js`، `rules-engine.js` و PostgreSQL استفاده می‌کند.
- نقش، رأی، اکشن شب، حذف، نتیجه، سکه و جایزه بازی آنلاین فقط در سرور تعیین می‌شوند.
- فایل `online-compat.test.js` تطابق فهرست ۱۶ نقش، تقسیم جناحی ۵/۲/۹ و تنظیمات اصلی سناریوی امپراتوری سایه‌ها را بین دو موتور در CI کنترل می‌کند.
- `offline-engine.test.js` آزمون‌های مستقل موتور آفلاین را به اجرای عمومی `npm test` اضافه می‌کند.

## محدودیت‌ها
ربات‌ها جایگزین بازیکنان واقعی نیستند. ذخیره محلی WebView، فروشگاه نمایشی، پرداخت، پیامک، کیف پول، جوایز، کانال صوتی و بازی چنددستگاهی در این موتور عملیاتی نیستند. هیچ داده‌ای از این محیط نباید به کیف پول یا رتبه‌بندی آنلاین منتقل شود.

## آزمون
از ریشه مخزن:
```sh
npm test
```

هر تغییری در ترکیب نقش‌ها یا قوانین پرچمدار باید در هر دو موتور منعکس شود و تست سازگاری آنلاین/آفلاین سبز بماند.

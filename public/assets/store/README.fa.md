# CASPIAN Store Assets

فهرست یکپارچه دارایی‌های بصری فروشگاه در شاخه کاری CASPIAN.

- `catalog.html`: صفحه نمایش همه دارایی‌های فعلی با بارگذاری مستقیم SVGها.
- `../cosmetics/avatars.svg`: مجموعه مادر شامل ۳۴ آواتار، از جمله ۲۲ شخصیت کلاسیک/آغازین و ۱۲ شخصیت آخرالزمانی.
- `../cosmetics/avatar-gallery.html`: گالری یکپارچه و قابل جست‌وجوی همه ۳۴ آواتور، با فیلتر کلاسیک و آخرالزمانی.
- `../cosmetics/frames.svg`: ۱۵ دورقاب پروفایل.
- `../cosmetics/emojis.svg`: ۸ استیکر/واکنش.
- `../cosmetics/social-effects.svg`: ۷ نماد اسپیکر و ۸ جلوه رأی‌گیری.

جمع قابل نمایش در کاتالوگ: ۳۴ آواتار + ۱۵ قاب + ۸ استیکر + ۱۵ نماد اجتماعی = ۷۲ مورد.

قیمت خرید و مالکیت باید از کاتالوگ سمت سرور خوانده شود؛ این صفحه فقط گالری بصری است. اسپیکرها در پیاده‌سازی فعلی نماد/اعلان بصری هستند و به‌معنی فایل صوتی ضبط‌شده نیستند.
